# Per CLAUDE.md, the byte-exact corpus is the project's load-bearing
# correctness gate. `make wasm-check` (tools/wasm_gate.py +
# tools/run_wasm.sh + wasmtime) prints the current WASM numbers.
#
# Discipline (mirrors the corpus byte-exact gate):
#   - `make wasm-check` runs tools/wasm_gate.py.
#   - Rejects any commit that EITHER introduces a new failing test
#     not in this list (regression) OR keeps a test in this list that
#     now passes (golden out of date — close it AND remove from the
#     list, atomic).
#   - The list only ever SHRINKS. Adding a test requires a real reason.
#
# Grouped by likely cause. Each removal of an item from this list is
# a net improvement to the WASM target.

# --- 32-bit machine word (wasm32): storing a value beyond 2**31 into an
#     array, memoryview or struct field converts it through the 32-bit
#     mp_int_t and raises OverflowError, where the full arm's 64-bit word
#     holds it. MicroPython's 32-bit ports write such values byte-wise
#     (src/objects/containers/binary.zig does not yet). The other bignum
#     tests are judged against full's goldens (corpus/wasm-mpz-goldens.txt).

# --- misc per-test gaps ---
# Added 2026-06-11 with the CPython-friendly collections.deque (frozen-tiny
# petitpy-lib/collections.py).
#
# These two tests are literally named deque_micropython — they pin MP's
# strict deque semantics, not standard Python's:
#
#   deque_micropython: expects deque(()) to raise TypeError because MP makes
#                      maxlen mandatory. Also exercises the 3-arg
#                      deque((), 2, True) signature with MP's flags=True
#                      mode (raise on overflow).
#   deque_slice:       expects d[0:1] to TypeError because MP's deque doesn't
#                      support slicing. Ours does, because it's a list subclass.
#
# We deliberately shipped CPython-compatible deque(iterable) because BFS /
# sliding-window / queue code uses it that way universally. The MP-specific
# behavior is still available via `from ucollections import deque`. These
# tests stay failing on wasm by design; native (no frozen-tiny in the Debug
# corpus binary) uses ucollections.deque and still passes them.
deque_micropython
deque_slice
