Extensions

Browser extensions and offline projects built on the nanopython runtime — things that go beyond a single page. Each extension loads nanopython.wasm in a privileged context (background script, options page, popup) and runs Python source there.

Nano Build Monitor

A Chrome/Firefox extension that watches CI builds across Sourcehut, GitHub, and GitLab. Background polling, badge updates, options page, popup — all driven by Python sources running on the nanopython wasm runtime via the ADR-006 JS bridge. Originally a Prescrypt-targeted Python-to-JS extension; this is the in-progress nanopython port.
