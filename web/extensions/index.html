Extensions

Browser extensions and offline projects built on petitpy, for things that go beyond a single page. Each extension loads nanopython.wasm in a privileged context (background script, options page, popup) and runs Python source there.

Nano Build Monitor

A Chrome/Firefox extension that watches CI builds across Sourcehut, GitHub, and GitLab. Background polling, badge updates, options page and popup are all driven by Python sources running on petitpy's wasm build, through the JS bridge (ADR 006). Originally a Prescrypt-targeted Python-to-JS extension; this is the in-progress petitpy port.
