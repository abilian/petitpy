Tetris-lite

Pro-style demo of the nanopy library. A Game class owns the playfield + active piece; @on_key decorators bind input; a Ticker runs gravity. Everything else (the bridge, the DOM, the canvas property writes, the localStorage dance) is in the library.

Companion to snake-lite (kid-style: module-level functions, nanopy.run loop). Both share web/lib/nanopy.py via symlink.
