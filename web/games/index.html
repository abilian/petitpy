Games

Six classics, each written three ways against a small shared library (nanopy.py for Python, nanopy.js for JavaScript). Same game, same library shape, different writing style.

Pick a variant to play it. Each row is one game with three flavors:

Kid: Python, module-level functions, no classes or decorators Pro: Python, classes + @on_key decorators + Ticker JS: JavaScript, same library API, same writing style as the kid version
