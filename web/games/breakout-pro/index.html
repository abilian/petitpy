Breakout-lite

Move the paddle, bounce the ball, break the bricks. Pure procedural Python — module globals, a handful of helper functions (reset_bricks, bounce_off_paddle, handle_brick_hits), and the three loop hooks (update, draw, on_press).

Kid-style. Built on web/lib/nanopy.py. The bounce math is integer-only: the paddle imparts horizontal english based on hit position, capped so the ball never goes purely sideways.
