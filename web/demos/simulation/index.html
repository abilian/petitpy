Notes

The wasm instance boots once on page load. main.py wires the Start / Stop / Reset clicks and the slider inputs through the js bridge, then exits. From then on every click and every animation frame fires straight into the still-live Python module. Sliders are integer-valued (and rate sliders are pre-scaled by Q=1000) so the float-less nano build never touches floats.
