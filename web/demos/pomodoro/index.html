Pomodoro timer, Python state machine

A classic 25/5/15 Pomodoro timer driven by Python. main.py owns the phase state machine, reads the duration inputs on Start, and ticks once per second via setInterval. JavaScript only boots the wasm; every DOM read, write, title-bar update, and color change goes through the ADR-006 js bridge.

Notes

Durations are read on Start, not on every input change — mid-session edits do not retro-resize the current phase. After four completed work sessions, the next break is a long one and the count resets. The card border and the browser tab title both track the current phase so the timer is glanceable from another tab.
