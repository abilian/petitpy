nanopython in the browser

A Zig/C strangler of MicroPython compiled to wasm32-wasi, running locally via @bjorn3/browser_wasi_shim. Python does the computation; JavaScript does the rendering. Pick a section below — everything runs entirely in your browser, no server. See the project page for the runtime itself.

Write Python, right here

An editor, a Run button, and the bytecode the compiler produced — the string table, the constants, then the opcodes for each scope. Load any of the 580 corpus programs known to run on wasm, or paste your own.
